Privacy Policy / プライバシーポリシー

CosmicVideoFactory Privacy Policy

Last updated: August 8, 2026

1. Information handled by the app / アプリが扱う情報

CosmicVideoFactory may handle local project files, generated video assets, TikTok OAuth authorization data, and upload-related metadata required to perform user-directed upload actions.

CosmicVideoFactory は、ローカルのプロジェクトファイル、生成された動画素材、TikTok OAuth 認証情報、利用者が指示したアップロード操作に必要なメタデータを扱う場合があります。

2. TikTok OAuth credentials / TikTok OAuth 認証情報

TikTok OAuth credentials are stored on the user's local PC. When available, the application uses Windows Credential Manager or another OS-provided secure credential store. The application does not operate an independent external server to collect or store these credentials.

TikTok OAuth 認証情報は利用者のローカルPCに保存されます。利用可能な場合、Windows Credential Manager などOSが提供する安全な認証情報ストアを使用します。本アプリは、これらの認証情報を独自の外部サーバーへ収集・保存しません。

3. Data sent to TikTok / TikTok へ送信されるデータ

When the user chooses to upload content, the application sends the minimum necessary data to TikTok through the TikTok API, such as authentication requests, upload metadata, and the selected video file.

利用者がアップロードを選択した場合、本アプリは TikTok API の利用に必要な範囲で、認証リクエスト、アップロード用メタデータ、選択された動画ファイルなどを TikTok へ送信します。

4. No independent collection server / 独自収集サーバーなし

This static website does not provide a personal information input form, database, or tracking service. CosmicVideoFactory does not use this website to collect users' TikTok credentials or project files.

この静的サイトには、個人情報入力フォーム、データベース、トラッキングサービスはありません。CosmicVideoFactory は、このサイトを使って利用者の TikTok 認証情報やプロジェクトファイルを収集しません。

5. Disconnecting access / 連携解除

Users can disconnect TikTok integration from within the application where supported, and can also revoke access through TikTok's account or developer settings.

利用者は、アプリ内の対応機能から TikTok 連携を解除できます。また、TikTok のアカウント設定または開発者向け設定からアクセス権を取り消すこともできます。

6. Updates / 更新

This policy may be updated when application behavior, TikTok API requirements, or applicable privacy requirements change.

本ポリシーは、アプリの仕様、TikTok API の要件、適用されるプライバシー要件の変更に応じて更新される場合があります。
